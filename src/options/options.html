PromptRelay settings

Your draft text is sent to the Gemini API when you click Improve prompt or when interception is on. It is not sent anywhere else.

Gemini

This key is separate from any ChatGPT or Claude subscription. Gemini API usage has its own free tier limits and possible charges. Check your Google account terms, including how free tier data may be used.

Model names change over time. If requests fail with a model error, pick a current one from the Gemini API docs.

How prompts are rewritten

Sent to Gemini with every improve request in Expand style, so keep it free of secrets. Up to 2000 characters. Leave empty and the rewritten prompt will include a line for you to fill in.

Cursor second reviewer (coding prompts)

Cursor redesigns the improved prompt for a coding agent: numbered requirements, edge cases, acceptance criteria and a plan first. It runs only when you click the button, in an empty temporary folder with no access to your code, and never edits anything. It needs the helper from helper/install.js and the Cursor CLI, and it uses your Cursor plan. You still choose what gets sent.
